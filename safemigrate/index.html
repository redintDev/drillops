Enforced Zero-Downtime Rule Taxonomy

SM-01: Volatile Column Default

Adding a column with volatile functions like gen_random_uuid() triggers a full table rewrite holding an AccessExclusiveLock. SafeMigrate suggests adding column null, setting default, and backfilling.

SM-02: Missing CONCURRENTLY

Standard CREATE INDEX takes a ShareLock that blocks all writes (INSERT/UPDATE/DELETE) for minutes or hours. SafeMigrate enforces CONCURRENTLY in non-transactional runners.

SM-03: Foreign Key Validation Scan

Adding a foreign key without NOT VALID scans entire millions of rows under lock. SafeMigrate splits it into metadata-only addition followed by non-blocking validation.

SM-04: Column Type Alteration

Altering column data types (e.g. integer to bigint) rewrites every tuple in the table. SafeMigrate generates dual-write column migration steps.

SM-05: Drop Column Queue Starvation

Dropping a column requires AccessExclusiveLock. Without lock_timeout, slow active queries block the drop, starving the entire connection pool.

SM-06: Missing Lock Timeout

Every production DDL script must set SET lock_timeout = '2s'; to fail fast rather than stalling all customer traffic behind a pending schema lock.

Drop-In CI/CD & Developer Setup

Turnkey GitHub Action

Blocks pull requests containing dangerous database locks and posts step summary diffs with automated safe rewrites.

- uses: actions/checkout@v4 - uses: redintDev/drillops/safemigrate@main with: path: "migrations" dialect: "postgresql" suggest-fixes: "true"

Git Pre-Commit Hook

Stops dangerous DDL from being committed to git branches or rewrites SQL in-place automatically.

# .pre-commit-config.yaml repos: - repo: https://github.com/redintDev/drillops rev: main hooks: - id: safemigrate-fix # rewrites SQL in-place - id: safemigrate-check # fails commit if unsafe
